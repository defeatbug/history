# 后台管理界面

**范围**：`/admin` 下的全部路由（内容管理 + 学习统计）
**模式**：Operate —— 用户是来完成任务的，不是来表达的

## 受众与任务

唯一的管理员（毕设作者）。桌面为主、手机为辅。没有审核流、没有第二个管理员。
任务：定位内容 → 编辑 → 保存；调整展示顺序；查看学生学习概览。
内容规模：14 门课程 / 102 道题 / 15 个历史事件 / 8 座博物馆 / 13 件文物 / 10 枚勋章。
硬约束：手机必须可用；不做草稿态、不做批量操作、不做分页。

## 选定方向

常规范式（standing exit）。工艺标尺：**Linear** 的列表密度与克制、**Stripe Dashboard**
的信息层级与状态完整度、**Supabase Dashboard** 的表格范式（同技术栈）。

记忆点：**影响面常驻** —— 管理员编辑任何内容时都能看到它波及多少学生数据，
而不是等点下删除才弹出提示。

## 未决事项

第二批三张表（`history_events` / `museums` / `artifacts`）的表单字段顺序尚未确定。

## Direction contract

**THESIS**
这个界面拥有的想法：**影响面常驻** —— 编辑任何内容时都能看到它波及多少学生数据，
而不是等点下删除才弹窗。它拒绝的默认编排：把「编辑」与「后果」分离的纯列表 + 纯表单两段式后台。

**OWN-WORLD**
极浅暖灰地面（`#f7f6f4`）上的白色圆角卡片；侧栏与地面同色、无描边、纯文字导航 + 分组标题，
激活项是琥珀胶囊。顶栏右侧一个深色胶囊主按钮。统计带是**一个白色容器切成四段**、细分割线隔开。
筛选与警示均为白色胶囊，警示带深色圆形数字角标。卡片是「圆形封面 + 标题 + 副标题 +
带图标的元信息胶囊」，可带黄色警示块与琥珀动作按钮。末列为浅琥珀底色的汇总面板。
强调色琥珀 `#f59e0b` / 橙 `#f97316`，语义色 `#dc2626` / `#16a34a`，文本 `#111827` / `#6b7280`，
描边 `#e5e7eb`。圆角 12~16px，阴影极浅。系统字体栈。
去掉全部内容后，这套「暖灰地面 + 白卡 + 单一暖色强调 + 细描边」仍然认得出是同一个产品。

**STORY**
管理员理解：系统里有多少内容、哪些需要处理、上次改了什么。
他相信：改动立即生效，且我能看到它波及谁（黄色警示块就长在卡片上，不需要点进详情）。
他做：定位 → 编辑 → 保存 → 看到确认，或直接把课程在难度列之间拖到正确位置。

**FIRST VIEWPORT**
左侧 232px 侧栏（HistoriaQuest 标识 + 概览 / 课程 / 事件 / 博物馆 / 文物 / 勋章 / 学习统计
+ 底部「返回学习端」）。右侧首行同一排放页面标题「课程」与深色胶囊主操作「新建课程」；
其下一条白色统计带切成四段（内容总数 / 待处理 / 学生在学 / 本周答题）；
再下是筛选胶囊行与警示胶囊行；主体是**难度看板**：初级 / 中级 / 高级三列，
每列头部为「难度名 + 计数角标 + 右对齐的题数均值」，列内是课程卡片，
卡片含圆形封面、课程名、时期与文明、题数胶囊，有学生学习过的课程带黄色影响面警示块。
看板下方仍是可折叠的表格视图（102 道题只能表格）。
